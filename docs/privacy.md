# LunaLauncher privacy policy

LunaLauncher does not collect, store remotely, sell or share any personal data. The app has
**no Internet permission**: nothing it handles can leave the device through it.

Everything below is processed and kept on the device only, and removed when the app is
uninstalled (or with Settings → Reset settings).

## Data kept on the device

- **Settings** you choose (layout, grid, dock, widgets, clock styles, icon picks, folders,
  hidden/locked/limited apps, app usage counters and last-used time for drawer ordering).
- **Settings backups** you export go to a file or the clipboard you choose. You decide where
  they are stored and who you share them with.

## Optional permissions

Each one is requested only when you turn on the feature that needs it, and can be revoked at
any time from Android settings.

| Permission | Used for | What is accessed |
| :--- | :--- | :--- |
| Contacts | Contact results in the drawer search | Contact names, only while searching |
| Calendar | The "next event" widget | Title and time of the next event in the coming week |
| Usage access | Screen time on the home screen and in widgets | Today's total foreground time |
| Notification access | Notification dots and the music widget | The **number** of notifications per app and the active media session; notification content is never read or stored |
| Accessibility service | Double tap to lock and app limits | Foreground app package names and window changes, to detect when a limited app opens or closes |
| Query all packages | Listing installed apps and icon packs | The list of installed apps, as any launcher needs |
