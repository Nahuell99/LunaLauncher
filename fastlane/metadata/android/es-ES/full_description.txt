<p><b>¿Usas tu teléfono o tu teléfono te usa a ti?</b></b><p><i>Olauncher</i> es un launcher para Android extremadamente minimalista, con las funciones justas. Por cierto, AF significa AdFree, es decir, sin anuncios. :D</p><p><br><b>FUNCIONES QUE PODRÍAN GUSTARTE:</b></p><ul><li><b>Pantalla de inicio minimalista:</b> Una experiencia limpia, sin iconos, anuncios ni distracciones. Te ayuda a reducir el tiempo de pantalla y aumentar la productividad.</li><li><b>Personalización:</b> Cambia el tamaño del texto, renombra aplicaciones, oculta las que no uses, muestra u oculta la barra de estado, ajusta la alineación del texto de las aplicaciones, etc.</li><li><b>Gestos:</b> Toca dos veces para bloquear la pantalla. Desliza hacia la izquierda o la derecha para abrir aplicaciones. Desliza hacia abajo para ver las notificaciones.</li><li><b>Fondo de pantalla:</b> Un nuevo y precioso fondo de pantalla cada día. Nadie dijo que un launcher minimalista tuviera que ser aburrido. :)</li><li><b>Privacidad:</b> No se recopilan datos. Launcher FOSS para Android. Código abierto con licencia GPLv3.</li><li><b>Funciones del launcher:</b> Temas claro y oscuro, compatibilidad con aplicaciones duales y perfiles de trabajo, y apertura automática de aplicaciones.</li></ul><p>Para mantener la sencillez de un launcher tan minimalista, algunas funciones específicas están disponibles, pero ocultas. Visita la página <b>Acerca de</b> en los ajustes para consultar la lista completa.</p><p><b>PREGUNTAS FRECUENTES:</b></p><ul><li><b>1. Aplicaciones ocultas</b> - Mantén pulsado cualquier punto de la pantalla de inicio para abrir los ajustes. Toca «Olauncher» en la parte superior para ver las aplicaciones ocultas.</li><li><b>2. Gestos de navegación</b> - Algunos dispositivos no admiten gestos con launchers de Android descargados. Solo el fabricante del dispositivo puede solucionarlo mediante una actualización.</li><li><b>3. Fondos de pantalla</b> - Este launcher para Android ofrece un fondo de pantalla nuevo cada día. También puedes elegir cualquier fondo desde los ajustes del teléfono o desde la aplicación Galería/Fotos.</li></ul><p>La página Acerca de de los ajustes incluye el resto de preguntas frecuentes y otros consejos para ayudarte a sacar el máximo partido a Olauncher. No olvides consultarla.</p><p><b>Servicio de accesibilidad:</b> Nuestro servicio de accesibilidad se utiliza exclusivamente para permitirte apagar la pantalla del teléfono con un gesto de doble toque. Es opcional, está desactivado de forma predeterminada y no recopila ni comparte ningún dato.</p><p>P. D.: Gracias por leer la descripción hasta el final.
